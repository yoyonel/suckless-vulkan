# Domain Glossary

## Visual Regression Testing

* **Golden Image**
  A pre-rendered, verified version of a frame used as the absolute reference to detect visual regressions. Generated by running tests with `SVK_UPDATE_REFERENCES=1`.

* **RMSE (Root Mean Square Error)**
  The authoritative metric for calculating visual deviation between a rendered frame and a Golden Image. By squaring the per-pixel error, RMSE mathematically guarantees that severe but localized visual corruptions (e.g., NaN artifacts, buffer overflows) trigger a failure, while smoothing out imperceptible, sub-pixel differences across the entire image.

* **RMSE Tolerance Threshold**
  The maximum allowable RMSE score for a test to pass. This is the sole source of truth for validation.
  *Anti-pattern:* Do not use "Deviant Pixel Percentage" (counting the number of wrong pixels), as it is binary and fails to capture the magnitude of the visual corruption, leading to both false positives (cross-driver parity issues) and false negatives (critical artifacts).

* **Cross-Driver Parity**
  The expected state where an image rendered on different GPU architectures (e.g., NVIDIA vs AMD) or drivers (RADV vs AMDVLK) produces visually identical results. Minor floating-point rounding errors or differing anti-aliasing rasterization rules are absorbed by the RMSE Tolerance Threshold.
